02 Rain & Weather — Regime States (4-Phase Lock)

The regime lock is a nested filter. You cannot trade at the micro level without the macro, structural, and window levels all being assessed. Each phase has a different time resolution, a different weight on the final score, and a different set of signals. The system never conflates them — merging timescales cancels them out (Contradiction C17, RESOLVED).

  • VIX thresholds: HALT 40, SIZE_HALVE 25, PENALTY_HIGH 30

  • Timeframe: 1H / daily

Tick / 1-Second

The MINE Stack: Multiplicative Tier Weighting

The four phases are not summed. They multiply, using the MADX MINE stack:

// M-I-N-E: each tier multiplies the base signal M = Micro-Execution tier × 1.50 I = Intermediate-Structural × 1.15 N = Normalized Clocks (time normalization, not a weight) E = Extended Macro-Regime × 0.65 // Threshold scaling across frames: Threshold_frame = Base_Threshold × sqrt(Frame_Seconds / 60) // A 15-min frame scales the threshold by sqrt(900/60) = 3.87x // A 1s frame keeps it near base (sqrt(1/60) ≈ 0.13x)
The macro gets the lowest weight (0.65x) because it changes the slowest and is the least specific to the current trade. The micro gets the highest (1.50x) because that is where the actual fill happens. This is counterintuitive: most systems over-weight the big picture and under-weight execution. This system does the opposite because the State Registry finding is clear — "the signal is in the execution, not the signal generator" (SEPARABILITY_FINDING, tier PROVISIONAL, 96% of losing trades are statistically indistinguishable from winners at entry).

03 Getting Jumped — Fluid Event Timing

In a street fight, you do not get to choose when the first punch arrives. You have to already be watching, already have your guard up, already know the escape routes. The system mirrors this: it must already be measuring when the market event arrives, because by the time you see the move, the opportunity window is already closing.

The Hawkes Self-Excitation Model

Market events cluster. A large trade triggers more large trades. A volatility spike triggers more volatility. This is modeled as a Hawkes process where past events increase the probability of future events:

// Hawkes intensity: current arrival rate λ(t) = μ + Σ αβ · e-β(t - ti) // Calibrated parameters (HFT Microstructure Research): μ = 0.244 // baseline arrival rate κ = 0.742 // branching ratio (sub-critical: < 1) β = 0.196 // decay rate // Reversion half-life: thalf = ln(2) / β = 3.54 seconds // Closed-form signature: C(τ) = κ · e-β(1-κ)τ

The branching ratio κ = 0.742 means each event generates 0.742 "child" events on average. The system is sub-critical (it doesn't explode), but heavily self-exciting — nearly three-quarters of observed events are triggered by previous events, not external news. The half-life of 3.54 seconds means the system's memory is short: if you are not already measuring when the cluster starts, you miss the entire window.

08 System Invariants & Non-Negotiables

1
NO_HARD_PRICE_STOP. The obsolete −8% hard stop killed 61.8% of winning CALLs (V6 Unified). The "universal stop must be impossible." The system uses a wrapper floor of −13.5% only if unavoidable, never a fixed percentage stop. Exit by the ladder, the quote lean, the path classifier — never by a price level.
2
OBJECTIVE_IS_PF_NOT_WIN_RATE. Win rate is vanity. PF is sanity. The 9-account live fleet runs 49.8% WR, PF 1.28 on 8,296 real round-trips. That 49.8% is the honest baseline — every backtest claiming 70%+ WR is suspect. Optimize for PF (Profit Factor = gross wins / gross losses) and expectancy ($/trade), never win rate.
3
SAMPLE_FAST_DECIDE_SLOW. The system gathers data at machine speed (17,000 points/sec/asset) but makes decisions at human speed (one trade at a time, with gates). A sealed holdout is opened once — if n < 30 per cell, the result is UNDERPOWERED and the look is burned. One failed configuration is one map cell, never a verdict.
